# Security

This is personal software: one deployment, one vault, its author's. There is no
bug bounty and no security team. There is one person who would like to know.

**Report privately** to hi@amirsalmani.com. Do not open a public issue for
anything that could let someone read, alter or lock a vault. Expect a reply
within a week; fixes land as ordinary commits with the finding named in the
message, after the deployment that matters is patched.

In scope: anything in this repository that a Bitwarden client would talk to.
Out of scope: the Bitwarden clients themselves, Cloudflare, and the age tool.

What is already written down and does not need reporting again:
[docs/ASSURANCE.md](docs/ASSURANCE.md) (no audit, and what is done instead) and
the *Stated limitations* section of the [README](README.md).
